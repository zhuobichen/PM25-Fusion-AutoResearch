# 创新方法指令

## 方法名称
WaveletGPR - 小波多尺度GPR残差融合法 (Wavelet Multi-scale GPR Residual Fusion)

## 创新点
使用离散小波变换（DWT）将CMAQ残差分解为多个空间尺度，对每个尺度独立建模后重构。现有GPR方法使用单一尺度核函数，无法同时捕获大尺度系统偏差（如区域传输偏差）和小尺度局地偏差（如城市热岛效应）。小波分解天然提供多尺度分析，且各尺度正交，避免尺度间干扰。

## 核心公式

### 步骤1：全局多项式校正
与PolyRK一致，使用OLS拟合二次多项式：
$$
\hat{y}_{poly}(s) = \beta_0 + \beta_1 \cdot M(s) + \beta_2 \cdot M(s)^2
$$
$M(s)$ 为CMAQ值，$\beta$ 由OLS解析求解。

### 步骤2：计算残差
$$
r(s_i) = y_{obs}(s_i) - \hat{y}_{poly}(s_i), \quad i = 1, ..., n
$$

### 步骤3：残差网格化
将散点残差插值到规则网格（用于小波分解）：
$$
r_{grid}(x, y) = \text{IDW}\left(\{r(s_i), s_i\}\right)
$$
使用反距离加权（IDW）插值到 $N_x \times N_y$ 网格。

### 步骤4：离散小波分解
对网格化残差进行2D-DWT分解：
$$
r_{grid}(x,y) = \sum_{k} c_{J,k} \phi_{J,k}(x,y) + \sum_{j=1}^{J} \sum_{k} d_{j,k} \psi_{j,k}(x,y)
$$
- $J$：分解层数（建议3层）
- $c_J$：最粗尺度近似系数（大尺度趋势）
- $d_j$：第j层细节系数（尺度j的局地变异）

### 步骤5：各尺度GPR建模
对每个尺度的系数独立建模：
$$
c_J(s) \sim GP(\mu_c, k_c(s,s')), \quad d_j(s) \sim GP(\mu_j, k_j(s,s'))
$$
各尺度核函数参数独立优化：
- 大尺度（$c_J$）：大相关长度 $\ell_c$，平滑核
- 细节尺度（$d_j$）：小相关长度 $\ell_j$，局地核

### 步骤6：小波重构
将GPR预测的各尺度系数重构：
$$
\hat{r}_{wavelet}(x,y) = \hat{c}_J + \sum_{j=1}^{J} \hat{d}_j
$$

### 步骤7：最终融合
$$
\hat{y}_{final}(s_0) = \hat{y}_{poly}(s_0) + \hat{r}_{wavelet}(s_0)
$$

## 关键步骤

1. **全局多项式校正**：
   - OLS拟合 $y = \beta_0 + \beta_1 M + \beta_2 M^2$
   - 解析解：$\beta = (X^TX)^{-1}X^Ty$

2. **残差计算与网格化**：
   - $r_i = y_i - \hat{y}_{poly,i}$
   - IDW插值到规则网格（网格分辨率≈CMAQ分辨率）

3. **小波分解**：
   - 使用PyWavelets库
   - 选择小波基：'db4'（Daubechies-4，适合大气数据）
   - 分解层数J=3

4. **各尺度GPR建模**：
   - 对每层系数拟合独立GPR
   - 核函数：RBF + WhiteNoise
   - 各尺度独立优化超参数

5. **GPR预测与重构**：
   - 对测试点预测各尺度系数
   - 小波逆变换重构残差场

6. **结果合成**：$\hat{y}_{final} = \hat{y}_{poly} + \hat{r}_{wavelet}$

## 参数清单

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| wavelet | str | 'db4' | 小波基函数 |
| decomposition_level | int | 3 | 分解层数 |
| grid_resolution | float | 0.1 | 网格分辨率（度） |
| poly_degree | int | 2 | 多项式阶数 |
| gpr_kernel | str | 'RBF+WhiteNoise' | GPR核函数 |

## 创新判定分析

### 排除规则检查
- [ ] 是否使用权重学习（Ridge/Lasso等）？→ **否**
- [x] 是否有物理可解释性？→ **是**
  - 多项式校正：CMAQ系统偏差（物理驱动）
  - 小波分解：空间尺度分离（大气过程的多尺度特性）
  - 各尺度GPR：不同物理过程主导不同尺度

### 预期提升
- R²提升来源：多尺度分离避免大尺度趋势干扰局地建模
- 风险假设：网格化插值引入误差，小波边界效应
- 对比基准：PolyRK (R²≈0.91)，目标R²≥0.92

## 方法指纹
MD5: wavelet_multiscale_gpr_residual_db4_3level_v1

## 风险假设
1. IDW网格化可能丢失局地细节（站点稀疏区）
2. 小波边界效应可能在区域边缘产生伪影
3. 细节尺度GPR可能过拟合噪声（需正则化）
4. 计算量较大：需对每个尺度独立训练GPR

## 验证计划
1. 十折CV：对比PolyRK、AdvancedRK
2. 尺度贡献分析：各尺度对总残差的方差贡献比
3. 敏感性测试：分解层数J=2,3,4的影响
4. 计算效率：与标准GPR的计算时间对比

## 物理类比
- **大尺度（c_J）**：类似天气尺度的区域传输偏差，相关长度~100km
- **中尺度（d_2）**：类似城市/郊区差异，相关长度~20km
- **小尺度（d_1）**：类似站点局地效应，相关长度~5km
- 小波分解 ≈ 大气科学中的尺度分离分析
