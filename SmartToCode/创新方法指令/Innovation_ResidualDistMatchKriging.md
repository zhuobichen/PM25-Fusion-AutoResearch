# 创新方法指令

## 方法名称
ResidualDistMatchKriging（残差分布匹配克里金，RDMK）

## 方法指纹
`residual_distribution_matching_kriging_gamma_gaussian_v1`

## 创新点
**核心创新**：针对PM2.5残差的非高斯特性（右偏、重尾），使用参数化Gamma分布进行残差分布匹配，将非高斯残差变换为高斯变量后进行克里金插值，再反变换回原始尺度。

**创新依据**：
- PM2.5浓度呈右偏分布（Gamma/对数正态），残差同样具有偏态
- 现有克里金/GPR方法假设残差服从高斯分布，高浓度区建模不准确
- 参数化分布匹配比经验分位数映射更稳健（参数少、外推能力强）
- 与Copula方法相比更简单（仅处理边际分布，不建模联合依赖结构）

## 方法概述
三步法：（1）多项式校正CMAQ系统偏差；（2）Gamma分布匹配将残差变换为高斯变量；（3）在高斯空间进行克里金插值后反变换。

| 数据 | 格式 | 维度 | 单位 | 说明 |
|------|------|------|------|------|
| 监测站坐标 | array | (n_stations, 2) | 度 | 训练站经纬度 |
| 监测站PM2.5 | array | (n_stations,) | μg/m³ | 训练站观测值 |
| CMAQ网格值 | array | (n_grids,) | μg/m³ | 待预测网格的CMAQ值 |
| CMAQ网格坐标 | array | (n_grids, 2) | 度 | 待预测网格的经纬度 |

## 输出数据

| 数据 | 格式 | 单位 | 说明 |
|------|------|------|------|
| 融合预测值 | array | (n_grids,) | μg/m³ | 融合后的PM2.5浓度 |

## 核心公式

### 公式1：多项式校正
```
Ŷ(s) = β₀ + β₁ · CMAQ(s) + β₂ · CMAQ(s)²
```
- 使用OLS求解β₀, β₁, β₂
- 校正CMAQ的系统偏差（均值偏移和非线性响应）

### 公式2：残差计算
```
r(sᵢ) = Y(sᵢ) - Ŷ(sᵢ),  i = 1, ..., n_train
```
- Y(sᵢ)：训练站观测值
- Ŷ(sᵢ)：多项式预测值

### 公式3：Gamma分布拟合
```
r(sᵢ) + offset ~ Gamma(α, β)
```
- α：形状参数
- β：尺度参数
- offset：偏移量，确保所有值为正（取|r_min| + ε）
- 使用MLE估计α, β

### 公式4：Gaussian变换（正态得分变换）
```
z(sᵢ) = Φ⁻¹(F_Gamma(r(sᵢ) + offset; α, β))
```
- F_Gamma：Gamma分布的CDF
- Φ⁻¹：标准正态分布的逆CDF
- 将非高斯残差变换为标准高斯变量

### 公式5：高斯空间克里金
```
ẑ(s₀) = kᵀ · K⁻¹ · z
```
- k：待预测点与训练站之间的协方差向量
- K：训练站之间的协方差矩阵
- z：变换后的高斯残差向量
- 使用Matérn核函数：κ(h) = σ² · (2^{1-ν}/Γ(ν)) · (√(2ν)h/ℓ)^ν · K_ν(√(2ν)h/ℓ)

### 公式6：反变换（回原尺度）
```
r̂(s₀) = F_Gamma⁻¹(Φ(ẑ(s₀)); α, β) - offset
```
- Φ：标准正态CDF
- F_Gamma⁻¹：Gamma分布的分位数函数（逆CDF）
- 将高斯空间的克里金估计反变换回原始残差尺度

### 公式7：最终融合
```
Y_fused(s₀) = Ŷ(s₀) + r̂(s₀)
```
- 多项式校正值 + 分布匹配后的残差克里金估计

## 关键步骤

### 步骤1：多项式校正
- 用训练站数据拟合二次多项式 Y = β₀ + β₁·CMAQ + β₂·CMAQ²
- 计算训练站残差 r = Y - Ŷ

### 步骤2：分布拟合
- 对残差加偏移使其为正
- 用MLE拟合Gamma分布参数(α, β)
- 检验拟合优度（KS检验）

### 步骤3：正态得分变换
- 将Gamma分布的CDF应用于每个残差值
- 再用标准正态逆CDF变换为高斯变量
- 得到近似标准高斯分布的z值

### 步骤4：变异函数估计
- 在高斯空间计算实验变异函数
- 拟合Matérn核模型（估计范围、块金、形状参数）

### 步骤5：克里金预测
- 对每个待预测网格点，在高斯空间进行克里金插值
- 得到ẑ(s₀)

### 步骤6：反变换与融合
- 将ẑ(s₀)通过Gamma逆CDF反变换回原始尺度
- 加上多项式校正值，得到最终融合结果

## 参数清单

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| poly_degree | int | 2 | 多项式阶数（1或2） |
| matern_nu | float | 1.5 | Matérn核形状参数（0.5=指数，1.5=二阶，2.5=三阶，∞=高斯） |
| offset_factor | float | 1e-6 | 偏移量系数（ε = offset_factor × |r_min|） |
| variogram_model | str | 'matern' | 变异函数模型类型 |
| max_kriging_neighbors | int | 30 | 克里金最大邻域站点数 |

## 创新判定

### 主级创新条件
| 指标 | 要求 | 预期依据 |
|------|------|----------|
| R² | ≥ best_baseline_R² + 0.01 | Gamma分布匹配更准确地建模残差分布，减少高浓度区偏差 |
| RMSE | ≤ best_baseline_RMSE | 正确的分布变换使克里金权重更合理 |
| \|MB\| | ≤ best_baseline_\|MB\| | 分布匹配校正系统偏态 |

### 风险假设
1. **Gamma分布拟合质量**：残差可能不严格服从Gamma分布，需检验
2. **样本量依赖**：Gamma分布MLE需要足够样本（建议n≥30）
3. **边界效应**：极低/极高浓度区的分布匹配可能不稳定
4. **高斯假设验证**：变换后的z值需验证是否近似高斯（Shapiro-Wilk检验）

### 与现有方法的区别
- **与QuantileMapping的区别**：QM使用经验分位数（非参数），RDMK使用参数化Gamma分布（更稳健、可外推）
- **与CopulaSpatialFusion的区别**：Copula建模联合分布，RDMK仅处理边际分布（更简单）
- **与WaveletGPR的区别**：WaveletGPR使用小波分解，RDMK使用分布变换（不同数学工具）
- **与PolyRK/AdvancedRK的区别**：这些方法假设高斯残差，RDMK显式处理非高斯性

### 验证计划
1. 十折CV对比AdvancedRK（当前最优，R²=0.916）
2. 分浓度区间评估：低（<35）、中（35-75）、高（>75）μg/m³
3. 残差分布检验：Gamma拟合KS检验p值
4. 变换后高斯性检验：Shapiro-Wilk检验p值
5. 参数敏感性：多项式阶数(1,2)、Matérn ν(0.5,1.5,2.5)的影响
