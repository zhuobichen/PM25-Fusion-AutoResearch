# 复现方法指令

## 方法名称
CensoredExceedances（贝叶斯截断阈值融合法）

## 方法来源
- 论文：Spatio-temporal data fusion of censored threshold exceedances
- 作者：M. Daniela Cuba, Craig Wilkie, Marian Scott, Daniela Castro-Camilo
- 年份：2025
- arXiv：2504.20268

## 方法指纹
`bayesian_censored_exceedances_gpd_ar1_v1`

## 方法概述
针对PM2.5监测数据中常见的"截断"问题（低浓度值低于检测限，仅知其≤阈值），采用贝叶斯分层模型结合截断似然函数和广义帕累托分布（GPD）尾部建模，实现多源数据融合。

## 输入数据

| 数据 | 格式 | 维度 | 单位 | 说明 |
|------|------|------|------|------|
| CMAQ模拟值 | array | (n_grids, n_times) | μg/m³ | 化学传输模型输出（替代原文EAC4再分析数据） |
| 监测站观测值 | array | (n_stations, n_times) | μg/m³ | 地面监测站PM2.5浓度 |
| 截断阈值 u | float | 标量 | μg/m³ | 检测限/关注阈值（默认35 μg/m³，日均标准） |

## 输出数据

| 数据 | 格式 | 单位 | 说明 |
|------|------|------|------|
| 融合预测值 | array | (n_grids, n_times) | μg/m³ | 融合后的PM2.5浓度场 |
| 超标概率 | array | (n_grids, n_times) | 无量纲(0-1) | 浓度超过阈值u的概率 |
| 条件期望 | array | (n_grids, n_times) | μg/m³ | 给定超标条件下的期望浓度 |

## 核心公式

### 公式1：贝叶斯分层模型
```
Y(s,t) = μ(s,t) + w(s,t) + ε(s,t)
```
- Y(s,t)：位置s、时刻t的观测值
- μ(s,t)：均值成分（可设为CMAQ的线性函数）
- w(s,t)：时空潜过程
- ε(s,t) ~ N(0, σ²)：测量误差

### 公式2：截断似然函数
```
L(θ) = ∏_{Y_i ≤ u} F(u; θ) × ∏_{Y_i > u} f(Y_i; θ)
```
- 对于≤阈值u的观测：使用CDF F(u;θ)（仅知其低于阈值）
- 对于>阈值u的观测：使用PDF f(Y_i;θ)（精确值已知）
- 处理检测限问题，避免将截断值当作精确零值

### 公式3：广义帕累托分布（GPD）尾部模型
```
P(Y > y | Y > u) = (1 + ξ(y-u)/σ_u)^{-1/ξ}
```
- ξ：形状参数（控制尾部行为）
- σ_u：尺度参数
- 用于建模超标值的条件分布

### 公式4：时空潜过程（AR(1)结构）
```
w(s,t) = φ · w(s,t-1) + ν(s,t)
```
- φ：时间自相关系数
- ν(s,t)：空间相关的创新项

## 关键步骤

### 步骤1：数据准备
- 加载CMAQ网格数据和监测站数据
- 对齐时空维度
- 确定截断阈值u（建议：日均PM2.5标准35 μg/m³）

### 步骤2：均值成分建模
- 设定μ(s,t) = β₀ + β₁ · CMAQ(s,t)
- 使用最大似然估计（MLE）拟合β₀, β₁

### 步骤3：截断似然拟合
- 对于Y ≤ u的观测，计算截断似然贡献
- 对于Y > u的观测，计算精确似然贡献
- 联合估计模型参数θ = (β, σ², φ, ξ, σ_u)

### 步骤4：GPD尾部拟合
- 对超过阈值u的观测值拟合GPD
- 估计形状参数ξ和尺度参数σ_u

### 步骤5：时空融合
- 利用AR(1)潜过程建模时空相关性
- 通过MLE（替代原文MCMC）估计潜过程参数

### 步骤6：预测输出
- 计算融合预测值：Ŷ(s₀,t) = μ̂(s₀,t) + ŵ(s₀,t)
- 计算超标概率：P(Y > u | data)
- 计算条件期望：E(Y | Y > u, data)

## 参数清单

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| threshold_u | float | 35.0 | 截断阈值（μg/m³） |
| xi_init | float | 0.1 | GPD形状参数初始值 |
| sigma_u_init | float | 10.0 | GPD尺度参数初始值 |
| phi_init | float | 0.5 | AR(1)时间自相关系数初始值 |
| spatial_range | float | 50.0 | 空间相关范围（km） |
| max_iter | int | 1000 | MLE最大迭代次数 |

## 适配说明

### 与原文的差异
1. **数据源替换**：原文使用EAC4再分析数据，本方案使用CMAQ模拟数据
2. **推断方法简化**：原文使用MCMC贝叶斯推断，本方案使用MLE（最大似然估计）以提高计算效率
3. **应用场景适配**：原文针对卫星/再分析数据融合，本方案针对CMAQ-监测数据融合

### 与现有方法的区别
- **与BayesianDA的区别**：BayesianDA使用标准贝叶斯同化，本方法引入截断似然处理检测限
- **与MLE-OI的区别**：MLE-OI假设高斯误差，本方法使用GPD处理尾部非高斯性
- **与QuantileMapping的区别**：QM使用经验分位数，本方法使用参数化GPD模型

## 风险假设
- MLE替代MCMC可能损失不确定性量化精度
- GPD尾部模型在小样本下可能不稳定
- AR(1)时间结构可能过于简单（可考虑AR(2)或ARMA）

## 创新判定
本方案为复现方法，不追求创新指标提升。目标是验证截断似然+GPD框架在PM2.5融合中的有效性。
