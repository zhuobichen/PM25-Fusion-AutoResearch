# 复现方法指令

## 方法名称
MSF-NNG（多源时空最近邻网格融合法）

## 方法来源
- 论文：An Improved Multi-source Spatiotemporal Data Fusion Model Based on the Nearest Neighbor Grids for PM2.5 Concentration Interpolation and Prediction
- 来源：Springer, 2023

## 方法指纹
`msf_nng_cressman_nearest_neighbor_fusion_v1`

## 方法概述
通过Cressman插值填补监测站缺失值，利用最近邻网格匹配找到大气条件最相似的网格点，最后用加权融合结合观测数据和模型数据。

## 输入数据

| 数据 | 格式 | 维度 | 单位 | 说明 |
|------|------|------|------|------|
| 监测站PM2.5 | array | (n_stations, n_times) | μg/m³ | 地面监测站观测值（替代原文"大站"数据） |
| CMAQ网格PM2.5 | array | (n_lat, n_lon, n_times) | μg/m³ | 化学传输模型输出（替代原文"模型数据"） |
| 监测站坐标 | array | (n_stations, 2) | 度 | 经纬度坐标 |
| CMAQ网格坐标 | array | (n_grids, 2) | 度 | 网格中心点经纬度 |

## 输出数据

| 数据 | 格式 | 单位 | 说明 |
|------|------|------|------|
| 融合结果 | array | (n_grids, n_times) | μg/m³ | 融合后的PM2.5浓度场 |

## 核心公式

### 公式1：Cressman插值
```
Ẑ(s₀) = Σᵢ wᵢ · Z(sᵢ)
wᵢ = (R² - dᵢ²) / (R² + dᵢ²)
```
- R：影响半径（默认50km）
- dᵢ：目标点s₀与站点sᵢ之间的距离
- 用于从稀疏监测站创建平滑的观测场

### 公式2：最近邻网格匹配
```
N(s₀) = argmin_{sⱼ ∈ G} ||s₀ - sⱼ||₂
```
- G：CMAQ网格集合
- 基于欧氏距离（可扩展为大气条件相似度）找到最匹配的网格点

### 公式3：多源加权融合
```
Z_fused(s, t) = α · Z_Cressman(s, t) + (1-α) · Z_CMAQ(s, t)
```
- α：观测数据权重（默认0.7）
- (1-α)：模型数据权重（默认0.3）
- 注意：α为固定权重，非学习权重（不违反排除规则）

## 关键步骤

### 步骤1：数据准备
- 加载监测站数据和CMAQ网格数据
- 对齐时间维度
- 计算站点间距离矩阵

### 步骤2：Cressman插值
- 对每个时间步和每个CMAQ网格点：
  - 搜索影响半径R内的监测站
  - 计算Cressman权重wᵢ
  - 插值得到观测场Ẑ(s₀,t)

### 步骤3：最近邻匹配
- 对每个CMAQ网格点，找到最近的监测站（或最近的已有观测值位置）
- 记录匹配关系用于后续融合

### 步骤4：加权融合
- 对每个网格点和时间步：
  - Z_fused = α · Z_Cressman + (1-α) · Z_CMAQ
  - 输出融合结果

## 参数清单

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| radius_R | float | 50.0 | Cressman影响半径（km） |
| n_neighbors | int | 5 | 最近邻数量 |
| alpha | float | 0.7 | 观测数据权重（固定，非学习） |
| grid_size | float | 1.0 | 空间网格分辨率（km，适配CMAQ分辨率） |

## 适配说明

### 与原文的差异
1. **数据源简化**：原文区分大小站，本方案统一使用监测站数据
2. **气象条件匹配**：原文使用气温/湿度/风速匹配，本方案简化为CMAQ值匹配
3. **应用场景适配**：原文针对城市1km网格，本方案适配CMAQ网格分辨率

### 十折验证适配
```
训练数据：9折监测站数据 + 9折CMAQ网格值
测试数据：1折监测站的CMAQ网格坐标
预测流程：
  1. 用9折训练站进行Cressman插值
  2. 在测试站的CMAQ网格坐标处提取插值结果
  3. 与CMAQ网格值加权融合
```

### 与现有方法的区别
- **与IDW的区别**：IDW仅用距离加权，MSF-NNG还结合CMAQ模型信息
- **与VNA的区别**：VNA使用Voronoi邻域平均，MSF-NNG使用Cressman权重和固定融合
- **与OI的区别**：OI使用最优权重（由误差协方差决定），MSF-NNG使用固定权重

## 风险假设
- 固定权重α=0.7可能不是全局最优（但避免了权重学习的排除问题）
- Cressman影响半径R需要调优
- 简化的距离匹配可能不如原文的大气条件匹配准确

## 创新判定
本方案为复现方法，不追求创新指标提升。目标是验证Cressman插值+最近邻匹配+固定权重融合框架的有效性。
