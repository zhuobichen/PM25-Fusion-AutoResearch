# 【可执行方法规范】

## 方法名称
卫星智能PM2.5传感器放置框架 (Satellite-informed Smart Sensor Placement)

## 文献来源
- 论文标题：Satellite-informed smart sensor placement framework for near-optimal PM2.5 monitoring in urban areas
- 作者：Environmental Science and Pollution Research Authors
- 年份：2024年
- 来源：Springer

## 核心公式

### 1. 多目标优化
$$
\min_{X} F(X) = [f_1(X), f_2(X), ..., f_k(X)]
$$
其中 $X$ 为传感器位置集合。

### 2. NSGA-II适应度
$$
\text{Fitness}(X) = w_1 \cdot \text{Coverage}(X) + w_2 \cdot \text{Variance}(X) + w_3 \cdot \text{Cost}(X)
$$

### 3. 空间覆盖度
$$
\text{Coverage}(X) = \frac{1}{|A|} \int_A \min_{x_i \in X} d(s, x_i) dA
$$

### 4. 信息增益
$$
\text{InfoGain}(X) = H(Y) - H(Y|X)
$$

## 参数清单

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| n_sensors | int | - | 传感器数量 |
| population_size | int | 100 | NSGA-II种群大小 |
| n_generations | int | 500 | 迭代代数 |
| crossover_rate | float | 0.9 | 交叉率 |
| mutation_rate | float | 0.1 | 变异率 |

## 数据规格

### 输入
| 数据 | 格式 | 维度 | 单位 |
|-----|------|-----|------|
| 卫星PM2.5 | array | (n_grids,) | μg/m³ |
| 地理协变量 | array | (n_grids, n_vars) | - |
| 道路网络 | shapefile | - | - |
| 人口密度 | array | (n_grids,) | 人/km² |
| 地形高程 | array | (n_grids,) | m |

### 输出
| 数据 | 格式 | 单位 |
|-----|------|------|
| 最优传感器位置 | array | (n_sensors, 2) |

## 实现步骤

1. **卫星数据分析**：获取卫星PM2.5空间分布
2. **地理协变量**：整合道路、人口、地形数据
3. **NSGA-II优化**：多目标优化传感器位置
4. **帕累托前沿**：生成非支配解集
5. **决策**：选择最优传感器配置方案
