# 【可执行方法规范】

## 方法名称
LUR - 土地使用回归法 (Land Use Regression)

## 文献来源
- 论文标题: 多种LUR研究 (Hoek et al., 2008; Wang et al., 2012)
- 方法: 利用土地使用、交通等地理变量预测空气污染

## 核心公式

### LUR模型:
$$
\hat{y}(s) = \beta_0 + \beta_1 \cdot X_1(s) + \beta_2 \cdot X_2(s) + ... + \beta_p \cdot X_p(s)
$$
其中 $X_p(s)$ = 土地利用特征（道路长度、人口密度、土地覆盖等）

### 逐步回归选择:
使用AIC/BIC准则逐步选择最优变量组合

### 空间验证:
留一交叉验证或k折交叉验证

## 参数清单

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| selection_criterion | str | 'AIC' | 变量选择准则 |
| max_vars | int | 20 | 最大变量数 |
| buffer_radius | list | [100,300,500,1000] | 缓冲半径(m) |

## 数据规格

### 输入
| 数据 | 格式 | 维度 | 单位 |
|-----|------|-----|------|
| 土地利用数据 | shapefile | - | - |
| 人口数据 | raster | (n_grid,) | 人/km² |
| 交通数据 | shapefile | - | - |
| 站点坐标 | array | (n_obs, 2) | 度 |

### 输出
| 数据 | 格式 | 单位 |
|-----|------|------|
| 空间预测场 | array | μg/m³ |

## 实现步骤

1. **数据收集**: 获取土地利用、交通、人口、地形等GIS数据
2. **缓冲区分析**: 在每个站点周围建立不同半径的缓冲区
3. **特征提取**: 计算每个缓冲区内的地理特征（道路长度、建筑密度等）
4. **逐步回归**: 使用AIC/BIC准则选择最优变量组合
5. **模型训练**: 拟合线性回归模型
6. **空间预测**: 对无监测区域进行PM2.5浓度预测
