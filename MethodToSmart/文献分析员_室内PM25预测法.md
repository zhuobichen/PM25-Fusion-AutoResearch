# 【可执行方法规范】

## 方法名称
室内PM2.5深度集成预测法 (Indoor PM2.5 Deep Ensemble Machine Learning, DEML)

## 文献来源
- 论文标题：Indoor PM2.5 forecasting and the association with outdoor air pollution: a modelling study based on sensor data in Australia
- 作者：Wenhua Yu, Bahareh Nakisa, Seng W. Loke, Svetlana Stevanovic, Yuming Guo, Mohammad Naim Rastgoo
- 年份：2024年
- arXiv: 2405.07404

## 核心公式

### 1. 三阶段深度集成框架
$$
\hat{y}_{DEML} = f_{meta}(f_1(x), f_2(x), f_3(x))
$$
其中 $f_1, f_2, f_3$ 为基础模型，$f_{meta}$ 为元模型。

### 2. 基础模型（3个）
- **XGBoost**: 梯度提升树
- **LightGBM**: 轻量梯度提升机
- **CatBoost**: 分类特征提升

### 3. 元模型（2个）
- **Ridge回归**: 线性融合
- **神经网络**: 非线性融合

### 4. 时滞特征构建
$$
x_t = [PM2.5_{out,t}, PM2.5_{out,t-1}, ..., PM2.5_{out,t-lag}]
$$

## 参数清单

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| lag_hours | int | 24 | 时滞小时数 |
| n_estimators | int | 1000 | 提升树数量 |
| max_depth | int | 6 | 最大树深度 |
| learning_rate | float | 0.01 | 学习率 |
| meta_model | str | 'ridge' | 元模型类型 |

## 数据规格

### 输入
| 数据 | 格式 | 维度 | 单位 |
|-----|------|-----|------|
| 室内PM2.5传感器 | array | (n_buildings, n_hours) | μg/m³ |
| 室外PM2.5 | array | (n_stations, n_hours) | μg/m³ |
| 气象数据 | array | (n_stations, n_hours, n_features) | - |

### 输出
| 数据 | 格式 | 单位 |
|-----|------|------|
| 室内PM2.5预测 | array | μg/m³ |

## 实现步骤

1. **数据收集**：91个室内传感器，24栋建筑，2019-2022年数据
2. **特征工程**：构建时滞特征、室内外比值特征
3. **基础模型训练**：分别训练XGBoost、LightGBM、CatBoost
4. **元模型训练**：使用基础模型预测结果训练元模型
5. **集成预测**：通过元模型融合基础模型输出
