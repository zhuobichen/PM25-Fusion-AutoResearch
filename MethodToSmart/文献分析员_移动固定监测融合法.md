# 【可执行方法规范】

## 方法名称
移动-固定监测数据融合法 (Mobile-Fixed Monitoring Data Fusion)

## 文献来源
- 论文标题：Integrating mobile and fixed monitoring data for high-resolution PM2.5 mapping using machine learning
- 作者：Rui Xu et al.
- 年份：2025年
- arXiv: 2503.12367

## 核心公式

### 1. 移动传感器校准
$$
PM_{2.5,mobile,calibrated} = f_{calibrate}(PM_{2.5,mobile,raw})
$$

### 2. 时空匹配
$$
PM_{2.5,matched}(s,t) = \frac{1}{|N(s,\Delta t)|} \sum_{(s_i,t_i) \in N(s,\Delta t)} PM_{2.5}(s_i,t_i)
$$

### 3. 机器学习融合
$$
PM_{2.5,fused} = f_{ML}(PM_{2.5,fixed}, PM_{2.5,mobile}, X_{covariates})
$$

### 4. 高分辨率映射
$$
PM_{2.5}(s) = f_{predict}(X(s)), \quad \text{分辨率: 500m, 5min}
$$

## 参数清单

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| n_mobile_sensors | int | 320 | 移动传感器数量（出租车） |
| n_fixed_stations | int | 52 | 固定监测站数量 |
| spatial_resolution | float | 500m | 空间分辨率 |
| temporal_resolution | float | 5min | 时间分辨率 |
| spatiotemporal_window | tuple | (500m, 5min) | 时空匹配窗口 |

## 数据规格

### 输入
| 数据 | 格式 | 维度 | 单位 |
|-----|------|-----|------|
| 移动传感器PM2.5 | array | (320, n_times) | μg/m³ |
| 固定站PM2.5 | array | (52, n_times) | μg/m³ |
| 气象数据 | array | (n_grids, n_times, n_vars) | - |
| 道路网络 | shapefile | - | - |

### 输出
| 数据 | 格式 | 单位 |
|-----|------|------|
| 高分辨率PM2.5 | array | μg/m³ |

## 实现步骤

1. **数据收集**：320个出租车传感器+52个固定站
2. **移动传感器校准**：建立与固定站的映射关系
3. **时空匹配**：500m/5min窗口匹配
4. **机器学习训练**：建立融合预测模型
5. **高分辨率映射**：生成500m/5min分辨率PM2.5地图
