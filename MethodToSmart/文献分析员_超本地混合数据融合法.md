# 【可执行方法规范】

## 方法名称
超本地混合数据融合法 (Hyperlocal Hybrid Data Fusion, RAMP)

## 文献来源
- 论文标题：A hyperlocal hybrid data fusion near-road PM2.5 and NO2 annual risk and environmental justice assessment across the United States
- 作者：Alejandro Valencia, M. Serre, S. Arunachalam
- 年份：2023年
- 来源：PLOS ONE
- DOI: 10.1371/journal.pone.0286406

## 核心公式

### 1. CMAQ区域模型
$$
C_{CMAQ}(s,t) = f_{CMAQ}(emissions, meteorology)
$$

### 2. R-LINE局部扩散模型
$$
C_{R-LINE}(s) = \sum_{i} \frac{Q_i}{2\pi \sigma_y \sigma_z u} \exp\left(-\frac{y^2}{2\sigma_y^2}\right) \left[\exp\left(-\frac{(z-H)^2}{2\sigma_z^2}\right) + \exp\left(-\frac{(z+H)^2}{2\sigma_z^2}\right)\right]
$$

### 3. RAMP融合
$$
C_{RAMP}(s) = C_{CMAQ}(s) + \Delta C_{R-LINE}(s)
$$
其中 $\Delta C_{R-LINE}$ 为R-LINE模型的局部增量。

### 4. 人口加权暴露
$$
E_{pop} = \sum_{s} C(s) \cdot Pop(s) / \sum_{s} Pop(s)
$$

## 参数清单

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| cmaq_resolution | float | 12km | CMAQ网格分辨率 |
| rline_resolution | float | 50m | R-LINE网格分辨率 |
| census_block | float | - | 人口普查区块 |
| emission_factors | dict | - | 排放因子 |

## 数据规格

### 输入
| 数据 | 格式 | 维度 | 单位 |
|-----|------|-----|------|
| CMAQ模拟 | array | (n_grids_12km, n_hours, n_species) | ug/m3 |
| 道路网络 | shapefile | - | - |
| 车流量 | array | (n_roads,) | 辆/天 |
| 排放因子 | array | (n_vehicle_types, n_pollutants) | g/km |
| 人口数据 | array | (n_blocks,) | 人 |

### 输出
| 数据 | 格式 | 单位 |
|-----|------|------|
| PM2.5/NO2暴露 | array | ug/m3 |
| 健康风险 | array | - |

## 实现步骤

1. **CMAQ模拟**：运行区域空气质量模型
2. **R-LINE建模**：建立道路局部扩散模型
3. **排放估算**：基于车流量和排放因子
4. **RAMP融合**：区域+局部模型融合
5. **暴露评估**：人口加权暴露计算
