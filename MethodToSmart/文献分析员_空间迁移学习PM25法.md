# 【可执行方法规范】

## 方法名称
空间迁移学习PM2.5估计法 (Spatial Transfer Learning for PM2.5 Estimation)

## 文献来源
- 论文标题：Spatial Transfer Learning for Estimating PM2.5 in Data-poor Regions
- 作者：Shrey Gupta, Andreas Zufle, Yongbee Park, Jianzhao Bi, Suyash Gupta, Avani Wildani, Yang Liu
- 年份：2024年
- arXiv: 2404.07308

## 核心公式

### 1. 源域模型
$$
f_S: X_S \rightarrow Y_S
$$
在数据丰富区域训练的模型。

### 2. 目标域适应
$$
f_T(x) = f_S(x) + \Delta f(x)
$$
其中 $\Delta f$ 为目标域的微调。

### 3. 域对抗损失
$$
\mathcal{L}_{domain} = -\sum_{i} [d_i \log D(x_i) + (1-d_i) \log(1-D(x_i))]
$$

### 4. 特征对齐
$$
\min_f \|MMD(X_S, X_T)\|^2
$$
最小化源域和目标域特征分布差异。

## 参数清单

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| source_regions | list | - | 源域区域列表 |
| target_region | str | - | 目标域区域 |
| fine_tune_epochs | int | 50 | 微调轮数 |
| domain_weight | float | 0.1 | 域对抗损失权重 |

## 数据规格

### 输入
| 数据 | 格式 | 维度 | 单位 |
|-----|------|-----|------|
| 源域PM2.5 | array | (n_stations_S, n_times) | μg/m³ |
| 目标域PM2.5 | array | (n_stations_T, n_times) | μg/m³ |
| 卫星AOD | array | (n_grids, n_times) | - |
| 气象协变量 | array | (n_grids, n_times, n_vars) | - |

### 输出
| 数据 | 格式 | 单位 |
|-----|------|------|
| 目标域PM2.5估计 | array | μg/m³ |

## 实现步骤

1. **源域训练**：在数据丰富区域训练基础模型
2. **特征提取**：学习可迁移的特征表示
3. **域对抗训练**：对齐源域和目标域特征分布
4. **目标域微调**：使用少量目标域数据微调
5. **预测**：在目标域生成PM2.5估计
