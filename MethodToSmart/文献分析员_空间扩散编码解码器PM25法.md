# 【可执行方法规范】

## 方法名称
空间扩散引导编码器-解码器PM2.5预报法 (Spatial-Diffusion guided Encoder-Decoder for PM2.5)

## 文献来源
- 论文标题：Spatio-Temporal Forecasting of PM2.5 via Spatial-Diffusion guided Encoder-Decoder Architecture
- 作者：Malay Pandey, Vaishali Jain, Nimit Godhani, Sachchida Nand Tripathi, Piyush Rai
- 年份：2024年
- arXiv: 2412.13935

## 核心公式

### 1. 图注意力层
$$
h_i^{(l+1)} = \sigma\left(\sum_{j \in N(i)} \alpha_{ij} W^{(l)} h_j^{(l)}\right)
$$
其中 $\alpha_{ij}$ 为注意力权重。

### 2. GRU单元
$$
r_t = \sigma(W_r [h_{t-1}, x_t])
$$
$$
z_t = \sigma(W_z [h_{t-1}, x_t])
$$
$$
\tilde{h}_t = \tanh(W [r_t \odot h_{t-1}, x_t])
$$
$$
h_t = (1-z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t
$$

### 3. 空间扩散建模
$$
C_{diffused}(s,t) = \sum_{j} A_{ij} C(s_j, t-\tau)
$$
其中 $A$ 为扩散邻接矩阵。

### 4. 编码器-解码器
$$
Encoder: h_t = f_{GRU-GNN}(x_t, h_{t-1})
$$
$$
Decoder: \hat{y}_{t+k} = g_{GRU}(h_t)
$$

## 参数清单

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| n_gnn_layers | int | 3 | GNN层数 |
| gru_hidden | int | 128 | GRU隐藏单元 |
| n_heads | int | 4 | 注意力头数 |
| seq_length | int | 24 | 输入序列长度 |
| forecast_horizon | int | 24 | 预报时长 |

## 数据规格

### 输入
| 数据 | 格式 | 维度 | 单位 |
|-----|------|-----|------|
| PM2.5时序 | array | (n_stations, n_hours) | μg/m³ |
| 气象特征 | array | (n_stations, n_hours, n_vars) | - |
| 空间邻接矩阵 | array | (n_stations, n_stations) | - |

### 输出
| 数据 | 格式 | 单位 |
|-----|------|------|
| PM2.5预报 | array | μg/m³ |

## 实现步骤

1. **图构建**：基于距离或风向构建空间图
2. **GNN编码**：图注意力网络提取空间特征
3. **GRU时序**：GRU捕捉时序依赖
4. **扩散建模**：模拟污染物空间扩散
5. **解码预测**：生成未来PM2.5预报
