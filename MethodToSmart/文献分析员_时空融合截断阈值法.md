# 【可执行方法规范】

## 方法名称
时空融合截断阈值超标法 (Spatio-temporal Data Fusion Censored Exceedances)

## 文献来源
- 论文标题：Spatio-temporal data fusion of censored threshold exceedances
- 作者：M. Daniela Cuba, Craig Wilkie, Marian Scott, Daniela Castro-Camilo
- 年份：2025年
- arXiv: 2504.20268

## 核心公式

### 1. 贝叶斯层次模型
$$
Y(s,t) = \mu(s,t) + w(s,t) + \epsilon(s,t)
$$
其中 $\epsilon(s,t) \sim N(0, \sigma^2)$。

### 2. 截断似然
$$
L(\theta) = \prod_{i: Y_i \leq u} F(u; \theta) \prod_{i: Y_i > u} f(Y_i; \theta)
$$
其中 $u$ 为阈值，$F$ 为CDF，$f$ 为PDF。

### 3. 极值理论模型
$$
P(Y > y | Y > u) = \left(1 + \xi \frac{y-u}{\sigma_u}\right)^{-1/\xi}
$$
广义帕累托分布(GPD)。

### 4. 时空潜在过程
$$
w(s,t) = \phi w(s,t-1) + \nu(s,t)
$$
AR(1)时间结构。

## 参数清单

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| threshold_u | float | - | 超标阈值 |
| xi | float | - | GPD形状参数 |
| sigma_u | float | - | GPD尺度参数 |
| phi | float | - | AR(1)系数 |
| spatial_range | float | - | 空间相关范围 |

## 数据规格

### 输入
| 数据 | 格式 | 维度 | 单位 |
|-----|------|-----|------|
| EAC4再分析 | array | (n_grids, n_times) | μg/m³ |
| 地面观测 | array | (n_stations, n_times) | μg/m³ |
| 阈值 | float | - | μg/m³ |

### 输出
| 数据 | 格式 | 单位 |
|-----|------|------|
| 超标概率 | array | - |
| 条件期望 | array | μg/m³ |

## 实现步骤

1. **数据准备**：EAC4再分析+地面观测
2. **阈值设定**：确定PM2.5超标阈值
3. **截断建模**：使用截断似然处理左截断数据
4. **GPD拟合**：对超阈值数据拟合广义帕累托分布
5. **时空融合**：贝叶斯层次模型融合多源数据
6. **超标预测**：生成超标概率和条件期望
